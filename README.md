# 🏎️ Formula 1 Report Analysis (1950–2025)

## 📌 Project Overview

This project analyzes **Formula 1 racing data from 1950 to 2025** using Python. It demonstrates the complete data analysis workflow, including data cleaning, preprocessing, exploratory data analysis (EDA), and visualization to uncover trends and insights from historical F1 race statistics.

---

## 🚀 Features

* 📊 Data Cleaning and Preprocessing
* 🧹 Handling Missing Values
* 🔄 Data Type Conversion
* 📈 Exploratory Data Analysis (EDA)
* 📉 Data Visualization
* 🏁 Analysis of Formula 1 historical statistics

---

## 🛠️ Technologies Used
